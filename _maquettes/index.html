Comment jouer

En jeu en 60 secondes

1

Lance Minecraft Java

N'importe quelle version fonctionne. Pour le meilleur ressenti PvP, on recommande la 1.8.9.

1.8 → 1.21+ acceptées
2

Ajoute le serveur

Multijoueur → Ajouter un serveur → colle l'adresse et rejoins.

3

Choisis ton kit

Clic droit sur le papier, prends un kit, saute dans l'arène. Gagne des coins à chaque kill pour débloquer les 15 kits.
